# Konten Sosial Media & Iklan dengan AI untuk UMKM

> Modul 2 dari 4 — khusus pemilik UMKM & e-commerce

## Tujuan Pembelajaran

Setelah modul ini, kamu bisa:
1. Membuat konten sosial media (caption, hashtag, visual) dengan AI
2. Membuat script video pendek (TikTok/Reels) dengan AI
3. Menjadwalkan konten secara konsisten dengan bantuan AI

## 1. Caption & Hashtag dengan AI

### Prompt untuk Caption Instagram

```
Buatkan caption Instagram untuk [PRODUK/JASA] dengan:
- Hook (1 kalimat menarik di awal)
- Body (2-3 kalimat value proposition)
- CTA (call to action)
- Emoji secukupnya (max 5)
- Hashtag: 10-15 hashtag relevan
Tone: [TONE]. Panjang: max 150 kata.
```

### Contoh Caption

> 🔥 Bosan dengan kue kering yang keras?
> Kue Kering Premium kami dibuat dengan mentega asli, renyah di luar, lembut di dalam. Cocok untuk lebaran, arisan, atau cemilan keluarga.
> 📱 Pesan sekarang via DM! Gratis ongkir Jakarta.
> 
> #kuekeringpremium #kuelebaran #umkmjakarta #jajananrumahan #kuekeringenak #oleholehjakarta #umkmindonesia #kuekeringmurah #cemilanenak #kuelebaran2025

### Latihan 1

Buat 5 caption untuk 5 produk/jasa berbeda.

## 2. Script Video Pendek (TikTok/Reels)

### Formula Script 15-30 Detik

| Waktu | Bagian | Contoh |
|-------|--------|--------|
| 0-3s | Hook | "Jangan beli kue kering sebelum nonton ini!" |
| 3-15s | Value | "Kue kering premium kami: mentega asli, 20 lapisan, renyah sempurna" |
| 15-25s | Proof | "Lihat sendiri: [demo gigitan]" |
| 25-30s | CTA | "Pesan via DM, gratis ongkir Jakarta!" |

### Prompt untuk Script Video

```
Buatkan script TikTok 30 detik untuk [PRODUK/JASA].
Format: [Waktu] [Visual] [Audio/Narasi]
Hook: menarik, 3 detik pertama
Value: manfaat utama
Proof: bukti/demo
CTA: ajakan bertindak
```

### Latihan 2

Buat 3 script video untuk produk/jasamu.

## 3. Content Calendar dengan AI

### Prompt untuk Content Calendar

```
Buatkan content calendar 1 bulan untuk UMKM [JENIS USAHA] di Instagram.
Posting 4x/minggu (Senin, Rabu, Jumat, Sabtu).
Sertakan: tanggal, tema, jenis konten (foto/video/carousel), caption singkat, hashtag.
Tema rotasi: edukasi, produk, testimoni, behind-the-scenes.
```

### Tips Konsistensi Konten

1. **Batch creation** — buat 1 minggu konten sekaligus (2-3 jam)
2. **Template** — buat 3-4 template visual, rotasi
3. **Reels > Foto** — algoritma IG/TikTok lebih suka video
4. **Engagement** — balas komentar dalam 1 jam pertama setelah posting

## 4. Visual & Design dengan AI

### Tools AI untuk Visual

| Kebutuhan | Alat | Kegunaan |
|-----------|------|----------|
| Desain grafis | Canva AI | Template, background removal, text-to-image |
| Foto produk | Remove.bg | Hapus background foto produk |
| Video editing | CapCut AI | Auto-caption, template, effects |
| Gambar AI | DALL-E / Midjourney | Gambar ilustrasi, konsep produk |

### Prompt untuk Visual

```
Buatkan deskripsi visual untuk [PRODUK] dengan:
- Style: [minimalist/colorful/elegant]
- Warna dominan: [WARNA]
- Elemen: [PRODUK + PROPS]
- Background: [DESKRIPSI]
- Mood: [MOOD]
```

## 5. Tips & Pitfalls

### ✅ Tips
- Gunakan AI untuk draft, kamu untuk finalisasi dengan brand voice
- Test 2-3 variasi caption, pilih yang engagement tertinggi
- Simpan konten yang perform bagus sebagai template

### ❌ Pitfalls
- Jangan gunakan gambar AI tanpa cek kualitas — bisa terlihat "fake"
- Jangan posting tanpa review — AI bisa salah fakta
- Jangan copy style kompetitor — temukan voice unikmu
