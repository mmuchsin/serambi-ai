# Materi Pembelajaran AI — Serambi.ai

Materi pembelajaran AI praktis untuk profesional non-teknis Indonesia.
Setiap modul dirancang untuk profesi spesifik, dengan contoh nyata dan latihan langsung.

## Struktur

```
materials/
├── 00-dasar-ai.md          # Fondasi AI untuk semua profesi (shared)
├── guru/                   # Guru (SD/SMP/SMA/SMK)
├── umkm/                   # Pemilik UMKM & e-commerce
├── ekspor-impor/           # Staff ekspor-impor & bea cukai
├── dokter/                 # Dokter & tenaga kesehatan
└── akuntan/                # Akuntan & finance
```

## Cara Menggunakan

1. **Goal Decomposer** menggunakan modul ini untuk menyusun roadmap mingguan
2. **Tutor Agent** (`explain_concept`) menjelaskan konsep dari modul ini dengan teknik Feynman
3. **Assessment Agent** (`generate_quiz`) membuat kuis berdasarkan modul ini
4. **Progress Agent** (`check_progress`) melacak penyelesaian modul

## Pedagogical Constraints

1. **Scaffold, not oracle** — materi memberikan struktur, bukan jawaban
2. **Graduated hinting** — hint bertahap untuk latihan
3. **Probing questions** — pertanyaan "mengapa?" dan "bagaimana?"
4. **No cognitive offloading** — materi tidak menyelesaikan tugas untuk learner
5. **Goal-first** — setiap modul dihubungkan ke profesi learner
