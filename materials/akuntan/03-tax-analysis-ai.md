# AI dalam Perpajakan & Analisis

> Modul 3 dari 3 — khusus akuntan & finance

## Tujuan Pembelajaran

Setelah modul ini, kamu bisa:
1. Menggunakan AI untuk perhitungan pajak
2. Membuat laporan pajak dengan AI
3. Menggunakan AI untuk analisis keuangan lanjutan

## 1. Perhitungan Pajak dengan AI

### Prompt untuk Perhitungan PPh

```
Hitung PPh 21 untuk karyawan dengan data berikut:
[NAMA, GAJI POKOK, TUNJANGAN, STATUS PTKP]
Sertakan: penghasilan bruto, pengurangan, penghasilan neto, PPh 21 terutang, dan take home pay.
Gunakan tarif pajak Indonesia terbaru.
```

### Prompt untuk PPh Badan

```
Hitung PPh Badan untuk PT dengan:
- Laba sebelum pajak: [X]
- Fiskal correction: [X]
- Fasilitas: [tax holiday/tax allowance jika ada]
Sertakan: penghasilan kena pajak, PPh terutang, dan angsuran PPh 25.
```

### Latihan 1

Hitung PPh 21 untuk 5 karyawan dengan data berbeda.

## 2. Laporan Pajak dengan AI

### Prompt untuk Laporan SPT

```
Buatkan checklist pengisian SPT Tahunan PPh Badan (1771) untuk PT [NAMA].
Sertakan: lampiran yang dibutuhkan, data yang perlu disiapkan, dan deadline.
```

### Latihan 2

Buat checklist SPT untuk 1 jenis badan usaha.

## 3. Analisis Keuangan Lanjutan

### Prompt untuk Financial Modeling

```
Buatkan model keuangan sederhana untuk [PROYEK/USAHA] dengan:
- Revenue projection (3 tahun)
- Cost structure (fixed + variable)
- Break-even analysis
- Cash flow projection
- Sensitivity analysis (best/base/worst case)
```

### Prompt untuk Valuasi

```
Estimasi valuasi perusahaan dengan metode [DCF/Multiple/Asset-based].
Data: [DATA KEUANGAN]
Sertakan: asumsi, perhitungan, dan range valuasi.
```

### Latihan 3

Buat financial model sederhana untuk 1 proyek/usaha.

## 4. Tools AI untuk Pajak & Analisis

| Kebutuhan | Alat | Kegunaan |
|-----------|------|----------|
| Perhitungan | Excel AI | Formula pajak otomatis |
| E-filing | DJP Online | Pelaporan pajak |
| Analisis | Power BI | Dashboard keuangan |
| Dokumentasi | ChatGPT/Claude | Draft laporan & analisis |

## 5. Tips & Pitfalls

### ✅ Tips
- Gunakan AI untuk perhitungan, tapi verifikasi dengan kalkulator pajak resmi
- Simpan template perhitungan yang berhasil
- Update tarif pajak secara berkala

### ❌ Pitfalls
- Jangan percaya 100% pada perhitungan AI — verifikasi
- Jangan input data klien ke AI publik
- Jangan gunakan AI untuk menggantikan professional tax advice
